# 理论增量：已推进结果与后续方向

## 已完成的增量

本轮没有增加无法核验的方向一致性假设来制造外层超线性。新增的是一个可实现的投影 continuation 变体及其独立保证，原来的 MEL/CONT 保证保持原有边界。

### 1. 不依赖正则项全局 Lipschitz 常数的阶段精度

令 z=prox_{αh}(w)、u=(w−z)/α，要求可检查的平滑梯度残差 ||∇f(w)+u||≤κα。假设 f 全局 μ-强凸、梯度 Lf-Lipschitz，h proper closed convex，prox 精确。由两个单调性不等式得到

α(||u||²−<u*,u>)≤||r||²/(4μ)，其中 u*=−∇f(x*)。

因此 ||u||≤||u*||+κ√α0/(2√μ)，并得投影点原问题误差 O(α²)。算法不需要知道 u*，只检查实际投影次梯度证书。常数仍可能依赖问题规模，不能称无维数影响。半空间指标函数的二维二次例子达到 Θ(α²)，且未投影点原目标为无穷，说明投影不是措辞区别。

这是对上轮单点证书的推进：增加了有界局部对偶量的推导、阶段规则、有限终止及锐性例子。基础工具仍是单调性和强凸性，不声称首次发现 Moreau 原始恢复。

### 2. 包含阶段内部工作的保证

P-CONT 在每个外层更新构造可计算参考梯度点。Newton 试探只有目标值不高于参考点时才采用；有固定试探与回溯上限，失败时返回参考点。每阶段先将暖启动目标与固定可行锚点比较。由此推导每阶段明确 K_j 上界，并求和得到 O(ε^{-1/2} log(1/ε)) 的更新/有界试探 oracle 次数上界。

这个上界包括所有阶段，不是把阶段数改称总复杂度。进一步给出了对角/固定块基础求解下包含曲率重建、谱检查、参考步和证书的单次运算成本。一般 proximal 或基础线性系统仍须另计成本。

这一保证无需固定内存 BFGS 满足 Dennis–Moré 条件，也无需 SSN 总能成功。它只属于带保障的新变体，不可转移给旧 CONT，更不是外层超线性定理。直接强凸近端梯度已有更好的 ε 阶依赖，所以这里证明的是带 Newton 试探的终止保障，而不是最优复杂度或方法优越性。

## 理论—实现对应

| 项目 | 理论要求 | 实现与核验 |
|---|---|---|
| 返回点 | z=prox(w)，证书在 z 计算 | P-CONT、CONT-P 显式返回 z；原始—对偶 gap 在该点计算 |
| 阶段门限 | ||r||≤κα | P-CONT κ=1，α乘0.1；无 Lh² 目标参数下限 |
| 可行锚点 | w0∈dom h，阶段初始目标不超过其目标 | 零向量，对比 Φα(w0)，必要时重置 |
| 保障 | Φα(w+)≤Φα(w−r/Lα) | 逐步直接检查，失败试探计数并退回参考点 |
| 试探成本 | 固定 inner/backtracking 上限 | 1000 次内层、50 次回溯；另有提前时间截断 |
| 总体终止 | 理论不设全局运行预算 | 实验设45秒和1200次外层预算，未达标按失败记录 |
| 原精度 | 投影次梯度证书或其他有效原证书 | 所有比较统一原始—对偶 gap，允许早于保守次梯度证书达标 |
| 非 Lipschitz h | 允许 extended-valued | 半空间锐性例子和二次正则检查；不是一般非可分 prox 成本结论 |

## 文献关系与新颖性边界

- Nesterov (2005), Mathematical Programming 103, 127–152, DOI 10.1007/s10107-004-0552-5：结构平滑及复杂度基础。
- Tran-Dinh (2016), arXiv:1509.00106v5：自适应平滑、加速近端梯度及一般复合结构；原文已核对。不能把自动改变 α 本身称为创新。
- Zheng, Zhang and Kwok (2016), AAAI, 2393–2399，作者原文 https://cse.hkust.edu.hk/~jamesk/papers/aaai16a.pdf：已经分析 continuation 全阶段工作；不能声称此前只有阶段数结果。

本稿增补的具体组合是投影残差、局部对偶量控制、允许指标正则的平方阶段误差、以及有成本上限的 Newton 试探保障。当前推导相对于旧稿有实质内容；是否构成足够文献原创性仍需更广泛同行核查，不能保证达到发表门槛。

## 下一步方向（未写成已证明结果）

1. **优先：减少保障成本。** 寻找保留理论下降条件、却不必每次额外计算参考目标的可认证接受准则。应给可计算证书及总成本，再做消融；不能仅删掉保障以换取时间优势。
2. **其次：加速参考机制。** 通过保持估计序列或严格重启分析降低最坏工作量。只要求 Newton 点目标更低，不自动保留加速证明；须新建耦合论证。
3. **结构方向：识别后的低维问题。** 对严格互补和部分光滑结构证明有限识别、稳定活动子空间中的曲率一致性。固定记忆一般不满足该条件；需要可检查的记忆增长/修正机制，并计入成本。
4. **精度方向：非精确 proximal。** 将 prox 误差同时传入平滑梯度和返回点证书，避免仅报告数值残差。当前定理不涵盖近似 prox 或严格浮点区间认证。

不建议继续把“无条件固定内存超线性”作为主攻结论。扩大规模实验表明投影策略能改善部分 continuation 成本，但未获得总体最快结果。下一步应优先处理弱正则下的残差尺度和参考保障成本，再决定投稿定位。

## 对实验停止规则的补充核查

对本实验的 ridge-logistic + 球支撑范数，固定 logistic dual 参数后，以投影次梯度 u 构造的原始—对偶 gap 恰等于 ||∇f(z)+u||²/(2τ)。实际 gap 进一步在所有对偶球变量上取最优，因此不大于该次梯度证书。实验只按共同 gap 停止，不会在精确算术中比定理的次梯度停止更晚。这条关系已补入附录说明，不能泛化到任意不同构造的 dual gap。

## 本轮最终实验结论

- 主实验165次：156次达标，9次未达标；四组保障消融12次全部达标，177个返回点已独立重算原问题间隙。
- P-CONT 在9组中的8组中位时间低于CONT，但没有一组总体最快。R-FISTA在7组中位最快，PQN在弱正则和更多样本两组中位最快。
- 16,000维：P-CONT 16.107秒、CONT 22.152秒、PN-MF 10.494秒、R-FISTA 3.847秒。矩阵自由PN在全部9组达标。
- 弱正则：P-CONT与去保障变体都需要1388次SSN，而CONT为908次。这里应优先修改残差阶段策略，不能把成本都归因于保障。
- 无回退的4,000维例子中，P-CONT与去保障变体都用700次SSN，但前者增加96次loss求值。保障的额外成本有直接计数证据。

这些结果没有证明新方法总体占优，也没有证明定理是文献中首次结果。相较上轮，实质推进在于有锐性例子的恢复误差、可运行的保障机制、完整阶段内部工作上界，以及扩大规模和矩阵自由对照。发表新颖性仍须进一步核查。
